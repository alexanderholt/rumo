# Available Advisors

These are on-demand specialists that Rumo's agents can dispatch when needed.

| Command | Role | When to use |
|---|---|---|
| `/expert` | On-demand domain expert | Research, draft, analyze, or build in any domain. Dispatched by Rumo for calibration reviews. |
| `/expert-review` | On-demand expert reviewer | Review work in any domain — dispatches a subagent for independent evaluation. |
| `/outside-specialist` | Outside specialist | Niche regulatory or legal domains where deeper expertise is needed. |
